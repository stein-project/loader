# The game no longer closes by itself, and the Tab list stays on top

Fixes you will notice while playing, and the base of the new API for mod developers.

- **The game no longer closes while loading chunks**: two threads could ask for a biome at the same time and break an internal list of the game, and the report for that error took the game down without warning. Fixed, and any error there produces a report in crash-reports again.
- **The Tab list stays on top of everything**: hotbar, armor and inventory icons no longer cut through the names.
- **The server list no longer fails the first time** it opens with Connect turned off.
- **Passwords kept by Windows**: a vault that only opens in your account, on your machine. Connect already keeps its proxy passwords there.
- **A mod can stay out of the list sent to servers**, if its author asks; it still shows in your mod list.
- **For mod developers** (experimental API, in the Stein SDK): per-mod settings and log, allies and enemies shared between mods, 2D drawing without OpenGL, items, effects, map, aiming with options, keys, chat, screens and more.

To update, open the installer again. Mods, options and worlds stay where they are.
