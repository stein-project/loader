# Stein Loader 0.1.25: the new Stein look

Stein now looks like the Stein Client: screens, HUD and icons share the same style.

- **Stein screens**: the menu, the Panel and the HUD editor use the Stein Client look, with its own fonts, smooth shapes and the launcher icons.
- **Stein font on the HUD**: everything on the grid (including chat, sidebar and boss bar) uses the Stein font. Each element has a **Font** option to go back to the game font. Symbols and server icons still show as usual. Menus and the rest of the game are unchanged.
- **Standard background**: every grid element has the same rounded background, with a **Background transparency** option. It replaces each element's own background.
- **Sliders**: scale and transparency are now adjusted by dragging, in the Panel and in the editor.
- **Tab**: while the list is open, grid elements underneath it are hidden.
- **Memory**: the game's default RAM is now 3 GB.
- **Components**: Stein Bridge 0.1.14 and Stein Loader 0.1.18.

To update, open the Stein Client or the installer again. Mods, options and worlds stay where they are.
