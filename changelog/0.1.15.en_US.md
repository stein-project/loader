# The installer brings the mods, and armor changes color again

Two things in this release: you download the installer once and it takes care of the mods, and resource packs that color armor by durability work again.

- **Pick the mods in the window**: one checkbox each, with name and version. On a fresh install they all come ticked; on an update, the ones you already have come ticked — and unticking one removes it from the folder. Running the installer again updates whatever is behind, and a new mod shows up for everyone without a new installer.
- **What is yours stays yours**: the installer only touches the mods on its list. Any other `.steinmod` in the folder is neither touched nor removed. Every file is verified before it lands (checksum), and with no connection it simply says so and installs the game as usual.
- **Armor that changes color as it wears out**: the `damage=86%-100%` rule in resource packs — the piece about to break — was dropped while reading the pack, so the inventory icon changed and the worn armor did not. The maths is now the same as OptiFine's, and each piece gets the color the pack drew for it.
