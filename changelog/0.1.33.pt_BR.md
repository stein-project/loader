# Stein Loader 0.1.33: nenhum mod é especial

O Loader não tem mais nada reservado para um mod específico.

- **Todos os mods em pé de igualdade**: o nome antigo dos ajustes de jogabilidade, mantido para que mods mais antigos continuassem carregando, saiu; os mods usam a API pública `Gameplay` (Stein SDK 0.2.4). Mods feitos para o Stein Loader 0.1.24 ou anterior que usavam esse nome precisam da versão nova: Combat 0.1.21 ou mais novo, que o Stein Client instala sozinho.
- **Os elementos de HUD de um mod novo começam desligados**: numa instalação do zero, os elementos de todos os mods começam desligados e você os liga no editor de HUD, igual para todos.
- **Componentes**: Stein Bridge 0.1.20 e Stein Loader 0.1.26.

Para atualizar, abra o Stein Client ou o instalador novamente. Mods, opções e mundos continuam onde estão.
