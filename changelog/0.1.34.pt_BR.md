# Stein Loader 0.1.34: downloads no repositório do próprio código

O instalador e os downloads dele agora vêm do repositório do próprio instalador, onde fica o código.

- **Um lugar novo para os downloads**: o instalador, os runtimes do Java e o arquivo com a última versão e os mods oficiais agora são publicados em [Stein-Project/installer](https://github.com/Stein-Project/installer/releases). Nada muda no jeito de instalar ou de jogar.
- **A mensagem do menu e o aviso de versão nova** também vêm do lugar novo, então acompanham cada versão nova.
- **Componentes**: Stein Bridge 0.1.20 e Stein Loader 0.1.27.

Para atualizar, abra o Stein Client ou o instalador novamente. Mods, opções e mundos continuam onde estão.
