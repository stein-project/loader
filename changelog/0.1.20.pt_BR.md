# Um instalador só, e suporte experimental a Linux e macOS

Até aqui o instalador só existia para Windows e pesava 54 MB, porque carregava o Java 25 do jogo dentro dele. Agora é **um arquivo só para os três sistemas**, com 9 MB, e o Java de cada um ele baixa na hora de instalar.

- **O mesmo `.jar` em Windows, Linux e macOS**: clique duplo, como sempre. Ele reconhece o seu sistema e baixa o Java 25 daquele sistema (uns 47 MB) — o download é a **primeira** coisa que ele faz, antes de tocar em qualquer arquivo, e o que chega é conferido pelo sha256 antes de entrar. Se a internet falhar, ele diz isso e não deixou nada pela metade.
- **Quem já tem o Java não baixa de novo.** A marca é do próprio Java, e não da versão do instalador: atualizar o Stein Loader não repete o download enquanto o Java for o mesmo.
- **Linux e macOS são experimentais nesta versão.** No Linux a instalação e o jogo foram conferidos do começo ao fim; no macOS ainda não rodamos numa máquina de verdade. Se você for o primeiro, conte como foi.
- **No macOS o aprimoramento gráfico não está disponível**, por limitação do OpenGL do sistema: ele pede recursos de shader que o macOS não oferece no modo de que o 1.8.9 precisa. O jogo, o motor e os mods funcionam normalmente.

No Windows, quem não tem Java nenhum continua com o `SteinLoader-Installer-windows.zip`: ele leva tudo dentro, como antes.
