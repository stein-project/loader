# Stein Loader 0.1.34: downloads from their own repository

The installer and its downloads now come from the installer's own repository, where its code lives.

- **A new home for the downloads**: the installer, the Java runtimes and the file with the latest version and the official mods are now published in [Stein-Project/installer](https://github.com/Stein-Project/installer/releases). Nothing changes in how you install or play.
- **The menu message and the update warning** come from the new place too, so they keep up with every new version.
- **Components**: Stein Bridge 0.1.20 and Stein Loader 0.1.27.

To update, open the Stein Client or the installer again. Mods, options and worlds stay where they are.
