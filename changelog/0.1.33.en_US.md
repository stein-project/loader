# Stein Loader 0.1.33: no mod is special

The Loader no longer has anything reserved for a particular mod.

- **Every mod on equal terms**: the old name of the gameplay switches, kept so that older mods would still load, is gone; mods use the public `Gameplay` API (Stein SDK 0.2.4). Mods built for Stein Loader 0.1.24 or older that used it need their new version: Combat 0.1.21 or newer, which the Stein Client installs on its own.
- **A new mod's HUD elements start off**: on a fresh install, every mod's elements start disabled and you turn them on in the HUD editor, the same for all mods.
- **Components**: Stein Bridge 0.1.20 and Stein Loader 0.1.26.

To update, open the Stein Client or the installer again. Mods, options and worlds stay where they are.
