# One installer only, and experimental support for Linux and macOS

Until now the installer only existed for Windows and weighed 54 MB, because it carried the game's Java 25 inside it. It is now **one file for all three systems**, 9 MB, and it downloads the Java for yours at install time.

- **The same `.jar` on Windows, Linux and macOS**: double-click, as always. It recognises your system and downloads the Java 25 for it (about 47 MB) — the download is the **first** thing it does, before touching any file, and what arrives is checked against its sha256 before going in. If the connection fails, it says so and nothing was left half done.
- **Whoever already has the Java does not download it again.** The mark is the Java's own, not the installer's version: updating the Stein Loader does not repeat the download while the Java is the same.
- **Linux and macOS are experimental in this version.** On Linux the install and the game were checked from start to finish; on macOS we have not run on a real machine yet. If you are the first, tell us how it went.
- **On macOS the graphics enhancement is not available**, because of an OpenGL limitation on that system: it asks for shader features macOS does not offer in the mode 1.8.9 needs. The game, the engine and the mods work normally.

On Windows, anyone with no Java at all still has `SteinLoader-Installer-windows.zip`: it carries everything inside, as before.
