# The installer opens with the Java you already have

People who play 1.8.9 through an alternative launcher open that launcher by double-clicking a `.jar` — and the Java doing that is usually Java 8. The installer asked for 17, so for exactly those people the file would not open. Now it does.

- **Opens on Java 8 or newer**: `SteinLoader-Installer.jar` is now compiled for Java 8. Java 25 still travels inside it and is what runs the game — what changed is only the Java needed to open the installer. No Java at all? The `.zip` still brings everything.
- **The bundled Java is replaced when it actually changes**: the installer decided whether the embedded Java was already there by comparing a file that does not tell one vendor from another, so it could keep an old runtime while reporting everything was up to date. Now whoever copied it leaves a mark with the version, and that is what answers.
- **The "close the launcher" warning works again** on Windows 11, which dropped from new installs the program the installer used to see what was running.
