# Stein Loader 0.1.37: the whole game on Vulkan

Stein now draws the whole game with Vulkan, the modern graphics API of your graphics card, and makes it the default: more FPS and steadier frames, with nothing changed in how the game looks or plays.

- **Vulkan by default**: the world, the creatures, the interface and the text go through Vulkan. In our tests the FPS came close to twice OpenGL's while the terrain loaded.
- **OpenGL where Vulkan does not run**: on a computer without Vulkan support, the game opens with OpenGL by itself. If Vulkan closes the game while it opens, the next start already uses OpenGL.
- **Your choice**: you can switch in the Stein Client's Settings, and the video options and F3 show which API is in use.
- **More FPS in crowded places**: crowds, player names and armor cost less every frame, on Vulkan and on OpenGL.
- **Cursor and window**: after an Alt+Tab the cursor is hidden again, and the window follows the mouse while you drag it.
- **Components**: Stein Bridge 0.1.23 and Stein Loader 0.1.29.

To update, open the Stein Client or the installer again. Mods, options and worlds stay where they are.
