# The screen editor stops losing your work

If two elements ended up touching, leaving the editor undid **everything** you had arranged in that session — with no warning. Anyone with a busy screen lived in that state, which is why it looked like the Loader simply did not save.

- **Leaving always saves.** The warning stays: touching elements turn red and the button reads "Overlapping". But it is now a warning, not a punishment — two things touching is yours to fix whenever you like; lost work does not come back.
- **The button works again** in that state. It used to be stuck, leaving Esc as the only way out, and Esc was exactly what threw the edits away.
- **Why it happened so often**: the editor measures each element from its preview (armor with all four pieces, effects with effects), which is larger than what shows in game — so a tidy screen could appear here with half a dozen elements in red.
