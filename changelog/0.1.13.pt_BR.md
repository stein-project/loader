# O instalador abre no Java que você já tem

Quem joga 1.8.9 por launcher alternativo abre o launcher com clique duplo num `.jar` — e o Java que faz isso costuma ser o 8. O instalador pedia o 17, então justamente para esse público o arquivo não abria. Agora abre.

- **Abre no Java 8 ou mais novo**: o `SteinLoader-Installer.jar` passou a ser compilado para o Java 8. O Java 25 continua indo dentro dele, e é ele que roda o jogo — o que mudou é só o Java necessário para abrir o instalador. Quem não tem Java nenhum continua com o `.zip`, que traz tudo.
- **O Java de dentro é trocado quando muda de verdade**: o instalador decidia se o Java embutido já estava instalado comparando um arquivo que não distingue um fabricante do outro, e por isso podia manter um runtime antigo dizendo que estava tudo em dia. Agora quem copiou deixa uma marca com a versão, e ela é que responde.
- **O aviso de "feche o launcher" voltou a funcionar** no Windows 11, que tirou das instalações novas o programa que o instalador usava para ver o que estava aberto.
