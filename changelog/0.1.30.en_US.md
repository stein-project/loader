# Stein Loader 0.1.30: open source

Stein Bridge and Stein Loader are now open source, under the Mozilla Public License 2.0, and reach you exactly as they are built.

- **Open source**: the code of the engine (Stein Bridge) and of the mod platform (Stein Loader) is public at github.com/Stein-Project. Anyone can read it, report a bug pointing at the exact line, and contribute. The jars are no longer obfuscated, so an error report names the real classes.
- **No more suggested servers**: Stein no longer adds servers to your multiplayer list.
- **New drawing API for mods**: mods can draw in the world and on screen the same way with Stein GFX and with the game's own pipeline. Mods that need it ask for Stein Loader 0.1.24.
- **Fixes**: clouds are drawn the usual way when Stein GFX cannot take them, and mods that ask for an old Loader version by number load again.
- **Components**: Stein Bridge 0.1.20 and Stein Loader 0.1.24.

To update, open the Stein Client or the installer again. Mods, options and worlds stay where they are.
