# Each element's options are saved again

Armor laid out horizontally or vertically, minimap style, what the Tab list shows: everything changed in an element's options card lasted only until you closed the game. It was not just the armor — it was every option of every mod element, and the mod's config file was never even created.

- **The editor now tells the mod when one of its options changes**, and the mod writes it straight away. The notice used to go out only on "restore defaults", so the one thing that did get saved was the default.
- **It covers every element and every mod** — HUD, Combat and whatever comes next — because the fix is in the Loader, not in each mod.
- Position, scale, "with chat open" and the game's own HUD parts already saved and are unchanged.
