# O editor da tela para de perder o que você fez

Se dois elementos ficassem encostados, sair do editor desfazia **tudo** o que você tinha arrumado naquela sessão — sem avisar. Quem tinha a tela cheia vivia nesse estado, e por isso parecia que o Loader simplesmente não salvava.

- **Sair sempre grava.** O aviso continua: os elementos que se tocam ficam vermelhos e o botão passa a dizer "Sobreposição". Mas agora é aviso, e não castigo — duas coisas encostadas você conserta quando quiser; trabalho perdido não volta.
- **O botão volta a funcionar** nesse estado. Antes ele ficava travado, sobrava o Esc para sair, e era justamente o Esc que apagava as edições.
- **Por que acontecia tanto**: o editor mede cada elemento pelo exemplo (a armadura com as quatro peças, os efeitos com efeitos), que é maior do que o que aparece em jogo — então uma tela bem arrumada podia aparecer no editor com meia dúzia de elementos em vermelho.
