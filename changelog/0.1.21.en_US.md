# Lighter on memory, and faster with a crowd around

Nothing changes visually: the game looks the same, it just weighs less.

- **Much less RAM.** The memory you pick in the installer is now the limit, not how much the game reserves on startup. Before, with 4 GB picked, Task Manager showed close to 4 GB all the time; now the game starts small and stays between 1.3 and 1.6 GB even with 400 players around, going above that only when it needs to. Fps and 1% lows stayed the same or got better. That leaves memory for Discord, the browser and the rest — on an 8 GB PC it makes a difference.
- **Up to 11% more fps with a crowd around.** Swords and other items in players' hands are now drawn from a stored copy instead of being rebuilt every frame. Dyed leather and potions are included too, each colour with its own.
- **Less memory garbage from nametags.** Every frame the game redid things that never change — the text shown when hovering a name, and a lowercase copy of the whole name for every colour code. Now that happens once.
- **Macs with Apple chips**: the installer asks the system which processor it has, instead of trusting the Java that opened it. Opening the installer with an old Intel Java used to leave the whole game running translated by Rosetta.
- **F3 shows how much each mod costs per frame**: if one is heavy, you can see which.

To update, open the installer again. Mods, options and worlds stay where they are.
